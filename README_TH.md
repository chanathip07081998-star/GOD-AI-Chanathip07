# GOD AI Starter 0.1

ต้นแบบผู้ช่วย AI ที่รันเป็นเว็บแอปบนเครื่องของคุณ มีแชตหลายข้อความ, ค้นเว็บผ่านเครื่องมือของ OpenAI API, อ่านไฟล์ TXT/MD/CSV/JSON/PY/LOG/PDF/DOCX, และดาวน์โหลดบทสนทนา

## สิ่งที่ต้องมี
- คอมพิวเตอร์ Windows / macOS / Linux
- Python 3.10 ขึ้นไป
- อินเทอร์เน็ต
- OpenAI API key และสิทธิ์ใช้โมเดลที่ระบุ (ค่า API อาจคิดแยกจาก ChatGPT)

สร้าง API key จากหน้า OpenAI API keys: https://platform.openai.com/api-keys

## เริ่มใช้งานบน Windows
1. แตกไฟล์ ZIP
2. ดับเบิลคลิก `start_windows.bat`
3. รอให้ติดตั้งไลบรารีเสร็จ เว็บแอปจะเปิดในเบราว์เซอร์
4. ใส่ API key ที่ช่องด้านซ้าย แล้วเริ่มพิมพ์คำสั่ง

## เริ่มใช้งานบน macOS / Linux
เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วรัน:
```bash
chmod +x start_mac_linux.sh
./start_mac_linux.sh
```

## ตั้งค่า API key แบบไฟล์ (ทางเลือก)
1. คัดลอก `.env.example` เป็น `.env`
2. ใส่ API key และชื่อโมเดลที่บัญชี API ของคุณเข้าถึงได้
3. อย่าแชร์ไฟล์ `.env` และอย่าอัปโหลดขึ้น GitHub

## วิธีใช้เอกสาร
1. อัปโหลดไฟล์จากแถบด้านซ้าย
2. กด “อ่านเอกสารที่อัปโหลด”
3. ถามคำถามเกี่ยวกับเอกสารในแชตได้ เนื้อหาเอกสารจะถูกส่งไปกับคำขอ AI

## ความปลอดภัยและขอบเขต
- แอปนี้เป็นต้นแบบผู้ช่วย ไม่ใช่ระบบที่ควบคุมทุกสิ่งได้ทันที
- ไม่ได้สั่งงานคอมพิวเตอร์หรือบัญชีภายนอกโดยอัตโนมัติ
- เปิดค้นเว็บได้จากสวิตช์ในแถบด้านซ้าย
- คำขอ API ใช้ `store=False` แต่ข้อความ/ไฟล์ยังถูกส่งไปยังผู้ให้บริการ API เพื่อประมวลผล อย่าอัปโหลดข้อมูลลับที่ไม่มีสิทธิ์ส่ง
- API key ที่กรอกในช่องจะอยู่ใน session ของแอป อย่าเปิดแอปให้ผู้อื่นใช้บนเครื่องที่ไม่ปลอดภัย
- ใช้เฉพาะระบบและข้อมูลที่คุณมีสิทธิ์เข้าถึง
- หาก API error ให้ตรวจสอบ API key, billing/เครดิต, model name, และสิทธิ์ของบัญชี

## ไฟล์หลัก
- `app.py` — เว็บแอป
- `requirements.txt` — ไลบรารี
- `.env.example` — ตัวอย่างการตั้งค่า
- `start_windows.bat` — ตัวเริ่มสำหรับ Windows
- `start_mac_linux.sh` — ตัวเริ่มสำหรับ macOS/Linux


## เผยแพร่เป็นเว็บไซต์ออนไลน์ (Streamlit Community Cloud)
การทำให้เป็นเว็บไซต์ที่เปิดได้จากมือถือทุกที่ ต้องเผยแพร่ไปยังบริการโฮสต์ก่อน โดยยังต้องให้เจ้าของบัญชีเป็นผู้อนุมัติการเผยแพร่

1. สร้างบัญชี GitHub และเชื่อมต่อ GitHub ในเครื่องมือที่รองรับ หรืออัปโหลดไฟล์โปรเจกต์นี้เป็น repository ส่วนตัว
2. อย่าอัปโหลดไฟล์ `.env` หรือ API key ไปยัง repository
3. เปิด https://share.streamlit.io/ แล้วเชื่อมบัญชี GitHub
4. เลือก repository, branch และไฟล์ `app.py`
5. ในส่วน Secrets ของแอป เพิ่มค่า:
   `OPENAI_API_KEY = "ใส่คีย์ของคุณ"`
   `OPENAI_MODEL = "ชื่อโมเดลที่บัญชี API ของคุณใช้ได้"`
6. กด Deploy แล้วรอให้บริการสร้าง URL เว็บไซต์
7. เปิด URL ที่ได้ใน Safari/Chrome บน iPhone หรือคอมพิวเตอร์

ข้อสำคัญ: ขั้นตอนนี้ยังไม่ได้ดำเนินการให้โดยอัตโนมัติ เพราะต้องใช้บัญชี GitHub/โฮสต์ของเจ้าของและการตั้งค่า API key ส่วนตัว อย่าส่ง API key ในแชตหรือใส่ไว้ในโค้ดสาธารณะ
